# Roadmap to 1.0.0

## Planned

These are the features/changes that will be needed before 1.0.0 is considered feature complete. In no particular order:

1. Vertical Text Support
2. Full WCAG 2.1 AA Compliance and Screen Reader Testing
3. Updated/Refined Document Model
4. Angular + React Packages
5. Table of Contents Ergonomics
6. Table Shading Fidelity
7. Float and Picture API (wrapping)
8. Shapes (Drawing ML + VML)
9. Text Effects
10. Underline Styles

## Deferred for Later Release

1. IME
2. Format Painter
3. HTML paste
4. Extensions surface for custom Skia rendering (like comment bubbles, custom rulers, etc.)
5. Equations

## Finished

1. Track Changes API / Document Model Support
2. Better Font Ergonomics
3. Deep API Overhaul
4. Bookmarks, Cross Reference
5. Cross-platform Dawn Support (Metal Arm64, Windows D3D12/D3D11/Vulkan, and WebGPU)
6. Float Improvements
