# Roadmap to 1.0.0

## Planned

These are the features/changes that will be needed before 1.0.0 is considered feature complete. In no particular order:

1. Track Changes API / Document Model Support
2. Vertical Text Support
3. Better Font Ergonomics
4. Full WCAG 2.1 AA Compliance and Screen Reader Testing
5. Updated/Refined Document Model
6. Deep API Overhaul
7. Angular + React Packages
8. Table of Contents Ergonomics
9. Bookmarks, Cross Reference
10. Table Shading Fidelity
11. Support more render instances (Metal, Windows Dawn (beyond Vulkan), Ganesh fallbacks)

## Deferred 

1. Shapes (Drawing ML + VML)
2. IME
3. Format Painter
4. HTML paste
5. Extensions surface for custom Skia rendering (like comment bubbles, custom rulers, etc.)
6. Text Effects
7. Equations
